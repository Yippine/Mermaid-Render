# Story 1.4: 智能語法容錯系統 - UI 測試指南

## 測試環境準備

### 前置條件

1. **啟動開發伺服器**: `npm run dev`
2. **訪問編輯器頁面**: `http://localhost:3000/zh-TW/editor`
3. **確認頁面載入**: 編輯器介面完整顯示

### 測試瀏覽器建議

- Chrome 最新版本 (推薦)
- Firefox 最新版本
- Safari (macOS)
- Edge (Windows)

## 功能測試步驟

### 🧪 測試 1: 語法分析基礎功能

#### 1.1 正確語法檢測

**測試步驟**:

1. 在左側編輯器輸入正確的 Mermaid 語法:
   ```mermaid
   graph TD
       A[開始] --> B{是否正確?}
       B -->|是| C[結束]
       B -->|否| D[修正]
       D --> A
   ```
2. 觀察語法分析面板（編輯器下方）

**預期結果**:

- ✅ 語法分析面板顯示「語法正確」或綠色勾選圖示
- ✅ 右側預覽面板正常渲染圖表
- ✅ 無錯誤提示

#### 1.2 錯誤語法檢測

**測試步驟**:

1. 在編輯器中輸入有語法錯誤的 Mermaid 代碼:
   ```mermaid
   graph TD
       開始 --> 處理資料
       處理資料 --> 判斷條件{是否正確
       判斷條件 -->|正確 完成任務
       完成任務 --> 結束
   ```
2. 等待語法分析（約 300ms 延遲）

**預期結果**:

- ❌ 語法分析面板顯示錯誤列表
- ❌ 錯誤項目包含具體位置和錯誤類型
- ❌ 右側預覽面板顯示錯誤訊息或降級處理
- 🔍 錯誤詳情可以展開查看

### 🧪 測試 2: 智能錯誤修復建議

#### 2.1 常見錯誤修復

**測試場景**:

1. **缺少引號錯誤**:
   ```mermaid
   graph TD
       A[節點 1] --> B[節點 2
   ```
2. **箭頭語法不一致**:
   ```mermaid
   graph TD
       A --> B
       B -> C
       C ==> D
   ```
3. **節點ID格式錯誤**:
   ```mermaid
   graph TD
       1節點 --> 2節點
       3-節點 --> 4節點
   ```

**預期結果**:

- 🔧 每個錯誤項目旁邊有「修復」按鈕
- 🔧 點擊修復按鈕後錯誤消失
- 🔧 修復後的代碼在編輯器中自動更新
- 📊 修復成功率顯示

#### 2.2 版本相容性處理

**測試步驟**:

1. 輸入 Mermaid v8/v9 舊版語法:
   ```mermaid
   graph TD
       A(圓形節點)
       B[方形節點]
       A --> B
   ```
2. 觀察版本相容性提示

**預期結果**:

- ⚠️ 顯示版本相容性警告
- 🔄 提供語法升級建議
- ✨ 可以一鍵轉換為最新版本語法

### 🧪 測試 3: 容錯級別控制

#### 3.1 容錯級別切換

**測試步驟**:

1. 在語法分析面板中找到容錯級別控制選項
2. 分別測試三種級別:
   - **嚴格模式**: 所有錯誤都報告
   - **標準模式**: 報告重要錯誤，自動修復小錯誤
   - **寬鬆模式**: 盡可能修復錯誤，只報告嚴重問題

**預期結果**:

- 🎚️ 三種模式切換正常
- 📈 不同模式下錯誤檢測程度不同
- 🔧 寬鬆模式自動修復更多錯誤
- 💾 設定記住使用者選擇

#### 3.2 自訂容錯規則

**測試步驟**:

1. 訪問容錯設定面板
2. 嘗試啟用/停用特定容錯規則
3. 測試自訂規則的效果

**預期結果**:

- ⚙️ 規則列表清晰顯示
- ✅/❌ 可以個別控制規則啟用狀態
- 🔄 規則變更即時生效
- 💾 自訂設定持久保存

### 🧪 測試 4: 漸進式語法解析

#### 4.1 部分錯誤隔離

**測試步驟**:

1. 輸入包含多個圖表區塊的代碼:

   ```mermaid
   graph TD
       A --> B
       B --> C

   graph LR
       錯誤語法 -->

   graph TB
       D --> E
       E --> F
   ```

2. 觀察渲染效果

**預期結果**:

- ✅ 正確的部分正常顯示
- ❌ 錯誤部分被隔離
- 📊 顯示語法健康度評分
- 🔍 清楚標示錯誤區塊位置

### 🧪 測試 5: 錯誤統計和分析

#### 5.1 錯誤統計面板

**測試步驟**:

1. 持續輸入不同類型的錯誤語法
2. 觀察錯誤統計資訊

**預期結果**:

- 📊 顯示錯誤類型分佈
- 📈 顯示錯誤嚴重程度統計
- 🎯 顯示修復成功率
- 📋 提供錯誤模式建議

### 🧪 測試 6: 效能測試

#### 6.1 響應速度測試

**測試場景**:

1. **小型圖表** (< 10 個節點): 分析時間應 < 50ms
2. **中型圖表** (10-50 個節點): 分析時間應 < 100ms
3. **大型圖表** (50-100 個節點): 分析時間應 < 200ms

**測試方法**:

- 開啟瀏覽器開發者工具
- 監控 Console 中的分析時間日誌
- 測量從輸入到結果顯示的延遲

#### 6.2 記憶體使用測試

**測試步驟**:

1. 開啟 Chrome DevTools -> Memory 面板
2. 進行長時間編輯和語法分析
3. 監控記憶體使用情況

**預期結果**:

- 💾 記憶體使用穩定，無明顯洩漏
- 🔄 垃圾回收正常運作
- 📉 長時間使用後記憶體增長 < 50MB

### 🧪 測試 7: 多語言支援測試

#### 7.1 語言切換測試

**測試步驟**:

1. 測試繁體中文 (`/zh-TW/editor`)
2. 切換到簡體中文 (`/zh-CN/editor`)
3. 切換到英文 (`/en/editor`)

**預期結果**:

- 🌐 所有介面文字正確翻譯
- 🔤 錯誤訊息使用對應語言
- 🎨 語言切換器正常運作
- 💾 語言偏好記住使用者選擇

#### 7.2 中文語法支援測試

**測試步驟**:

1. 輸入包含中文的 Mermaid 語法:
   ```mermaid
   graph TD
       開始 --> 處理資料
       處理資料 --> 判斷{是否正確?}
       判斷 -->|正確| 完成
       判斷 -->|錯誤| 重試
       重試 --> 處理資料
   ```

**預期結果**:

- ✅ 中文節點名稱正確處理
- ✅ 中文標籤正確顯示
- 🎨 UTF-8 編碼支援完整
- 🔧 中文相關錯誤正確檢測

## 邊界情況測試

### 🔍 極限測試

1. **空白輸入**: 編輯器完全清空
2. **極長輸入**: 超過 10,000 字元的代碼
3. **特殊字元**: 包含 emoji、特殊符號的語法
4. **格式錯亂**: 完全錯誤的語法格式

### ⚡ 效能邊界

1. **高頻輸入**: 快速連續輸入測試防抖機制
2. **並發分析**: 多個分析請求同時處理
3. **記憶體壓力**: 長時間高強度使用

## 預期問題和解決方案

### 常見問題

1. **語法分析延遲**: 檢查防抖設定 (300ms)
2. **修復按鈕無效**: 確認語法修復器正常運作
3. **主題顯示異常**: 檢查 Monaco 編輯器主題配置
4. **語言切換失效**: 確認 i18n 路由配置

### 錯誤排查

1. **Console 錯誤**: 開啟開發者工具檢查錯誤訊息
2. **網路請求**: 確認語法分析 API 調用正常
3. **狀態管理**: 檢查 Zustand store 狀態更新
4. **型別錯誤**: 確認 TypeScript 編譯無誤
