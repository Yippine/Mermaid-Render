# Epic 2: 國際化支援系統

## Epic 概述

**Epic 名稱**: 國際化支援系統 (Internationalization Support System)
**Epic ID**: Epic-2
**狀態**: 已完成 (Completed)
**優先級**: 中 (Medium)

## Epic 目標

建立完整的國際化系統，支援多語言介面和在地化內容，提供全球使用者更好的使用體驗。

## 商業價值

- **擴大用戶基數**: 支援多語言能夠吸引更多國際使用者
- **提升使用者體驗**: 母語介面提供更直觀的操作體驗
- **增強產品競爭力**: 在國際市場中具備本地化優勢
- **降低學習成本**: 減少非英語使用者的學習障礙

## 涵蓋的 Stories

### Story 2.1: 基礎國際化框架建立 ✅

- **狀態**: 已完成
- **描述**: 建立 next-intl 國際化框架和路由系統
- **實現內容**: 支援 en、zh-TW、zh-CN 三種語言

### Story 2.2: 介面文字國際化 ✅

- **狀態**: 已完成
- **描述**: 翻譯所有介面文字和訊息
- **實現內容**: 編輯器、預覽面板、錯誤訊息等全面翻譯

### Story 2.3: 語言切換功能 ✅

- **狀態**: 已完成
- **描述**: 提供動態語言切換功能
- **實現內容**: 語言選擇器和無縫切換體驗

## 技術架構

### 核心技術

- **next-intl v4.3.5**: Next.js 國際化框架
- **動態路由**: `/[locale]/` 路由結構
- **SSR 支援**: 伺服器端渲染多語言內容
- **型別安全**: TypeScript 完整型別支援

### 目錄結構

```
src/
├── app/[locale]/          # 國際化路由
├── i18n/                 # 國際化配置
├── messages/              # 語言包檔案
└── components/ui/         # 語言切換組件
```

## 支援語言

- **繁體中文 (zh-TW)**: 預設語言，台灣地區
- **簡體中文 (zh-CN)**: 中國大陸地區
- **英文 (en)**: 國際版本
